# Responsible AI use

Never paste passwords, API keys, access tokens, private keys, customer records, personal identifiers, confidential company code or private documents into an assistant without appropriate authorization. Use synthetic sample data instead. Keep secrets outside version control; `.gitignore` is a safeguard, not a guarantee.

Before accepting generated code, read it, check its assumptions and dependencies, inspect file operations, test normal and edge cases, verify errors and exit codes, and check licenses and security implications when relevant. Run in an isolated environment without unnecessary privileges. Disclose AI assistance honestly and record actual changes and test outcomes rather than claiming work you did not perform.
